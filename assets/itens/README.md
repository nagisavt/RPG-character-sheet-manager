Icones dos itens do inventario.

Um PNG por chave do Catalogo, no mesmo nome:
assets/itens/srd-2024_rope.png -> item "srd-2024_rope"

Os arquivos pretos aqui sao placeholder, gerados por `npm run assets:placeholders`.
A arte de verdade entra por cima, com o mesmo nome; o gerador nao sobrescreve
o que ja existe. Enquanto o desenho nao chega, a tela mostra o retangulo preto
com o nome do item em cinza claro.
