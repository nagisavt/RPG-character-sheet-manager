Icones dos itens do inventario.

Um PNG por chave do Catalogo, no mesmo nome:
assets/itens/srd-2024_rope.png -> item "srd-2024_rope"

Os pretos aqui sao placeholder, gerados por `npm run assets:placeholders`: o
retangulo preto com a chave escrita dentro, em cinza claro. A arte de verdade
entra por cima, com o mesmo nome; o gerador nao sobrescreve o que ja existe.
